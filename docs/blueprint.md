# **App Name**: CoursePilot

## Core Features:

- Planner Board: Interactive drag-and-drop interface for planning modules across semesters.
- Semester View: View modules in a grid format with semester-wise allocation.
- Study Group Plans: Allows grouping and displaying course plans by study groups.
- Template Management: Create template plans for different degree programs.
- Module Overview: Shows module details, filters, and edit options in a structured format.
- AI Course Optimization: Suggests ways to consolidate module offerings based on student enrollment and curriculum rules as a tool to reduce the total teaching hours, while respecting locked modules.
- Locking Modules: Locking mechanism on modules prevent specific modules from being moved, dropped, or consolidated when generating suggested changes.

## Style Guidelines:

- Primary color: Dark blue (#3F51B5) to provide a professional and calm feel.
- Background color: Dark gray (#212121) to reduce eye strain in long sessions.
- Accent color: Cyan (#00BCD4) to highlight interactive elements and important information.
- Body and headline font: 'Inter' (sans-serif) for clear and modern readability.
- Code font: 'Source Code Pro' (monospace) for displaying module IDs.
- Use minimalist, consistent icons from Material Design for clarity.
- Emphasize a clean, grid-based layout to maximize information density.
